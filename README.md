## 🛠️ Technology Stack
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS + Custom Glassmorphism + Neon Glow Shadows
- **3D Graphics:** Three.js (WebGL Particle Cosmos & Concentric Rings)
- **Animation:** Framer Motion (Kinetic Typography, Bento Grid, 3D Perspective Tilt)
- **Icons:** Lucide React
- **Celebration Effects:** Canvas Confetti
- **Audio:** Web Audio API Synthesizer
- **SEO / AEO / GEO:** Comprehensive JSON-LD Schema (`LocalBusiness`, `Organization`, `Service`, `FAQPage`)

## 🚀 Running the Project Locally

```bash
# 1. Install dependencies

# 2. Start development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview production build
npm run preview
```
